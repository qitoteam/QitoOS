# QDL — Qito Dynamic Libraries

`.qdl` is the native dynamic library format of QitoOS, a sibling to QTX.

## Format

Same `QX` header as QTX, with format byte `'D'` (instead of `'X'`).

Extension `.qdl`.

A QDL:

- has no entry point (must be 0)
- sets library flag (`QTX_FLAG_LIBRARY = 0x0002`)
- its symbol table is an export table other images link against

Header layout identical to QTX (88 bytes):

```
<QDL uses same struct qx_header as QTX, format='D'>
```

Validation in addition to QTX rules:

- entry_point must be 0
- library flag must be set
- W^X still rejected

## Loading

QDLs live in `/lib/*.qdl` on the root filesystem.

When loading a `.qtx`, the loader resolves each import:

1. First against kernel export table (`qtx_resolve_export`)
2. Then against any already-loaded QDLs (`qdl_resolve_symbol`)
3. On-demand: scan `/lib/*.qdl`, load first that exports needed symbol

If still unresolved → load-time error, never leave null service pointer.

Refcounting:

- Each QDL has refcount
- When a QTX uses a QDL, `qdl_retain` bumps refcount, and dependency recorded in `qtx_image.dep_qdl_ids`
- When QTX exits, `qtx_unload` calls `qdl_release_by_index` for each dep
- When refcount drops to 0, QDL is unloaded (free memory, symbols)

## Symbol resolution

Symbols in QDL are stored as `<24sQ` – name + virtual address.

At load time, lowest VA is recorded, and actual kernel address is computed as:

```
actual = image.base + (symbol.address - lowest_va)
```

`qdl_resolve_symbol` scans loaded QDLs and returns translated address.

## Commands

```bash
qdl list               # loaded QDLs
qdl load /lib/mylib.qdl
qdl unload mylib
qdl info /lib/mylib.qdl
```

## Building a QDL

```bash
qcc -shared -o libmylib.qdl mylib.c
# or
qasm -shared -o libmylib.qdl mylib.s
```

`-shared` sets library flag, clears entry.

Example in C:

```c
#include <qito/qtx.h> // SDK

int my_add(int a, int b) { return a+b; }

// Export table is generated by qcc from non-static functions
```

See `sdk/include/qito/qdl.h` for API.

## Integration with qtpkg

QDLs are installed via `qtpkg`:

```
qtpkg install libpng
# -> fetches profile -> payload http://.../libpng.qdl -> installs to /lib/libpng.qdl
```

`-fix --driver` also uses QDL path for driver repair.
